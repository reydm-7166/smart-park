# Smart Park

## Setup

### 1. Clone the Repository

```bash
git clone <repository-url>
cd <project-folder>
```

### 2. Create `application.properties`

Create the following file:

```text
src/main/resources/application.properties
```

Add the required application configuration to the file.
I will include the properties/values to be used here in the email upon submission. 
Just copy paste and paste in the created file (application.properties


### 3. Checkout to `develop`

```bash
git checkout develop
```

### 4. Build the Project

If you are using **IntelliJ IDEA**, open the project and build it using Maven.
